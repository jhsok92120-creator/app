# IQ·EQ 퀴즈

초등 3학년 이상을 위한 **IQ(생각하는 힘) · EQ(마음 읽는 힘)** 퀴즈 웹앱(PWA)입니다.

> 연습용 퀴즈입니다. IQ·EQ를 측정하는 검사가 아니므로 점수 대신 맞힌 개수와 채점 도장만 보여 줍니다.

## 구성
- **IQ 퀴즈** (60문제): 수 규칙 · 논리 추론 · 언어 추리 · 공간·도형 · 암호·기호
- **EQ 퀴즈** (48문제): 감정 알아차리기 · 입장 바꿔 생각하기 · 마음 다스리기 · 대화와 공감 · 갈등 해결
- IQ/EQ 버튼을 누르면 5개 영역에서 2문제씩, 모두 10문제가 무작위로 섞여 나옵니다.
- "영역을 골라서 연습하기"에서 한 영역만 8문제씩 풀 수 있습니다.
- 문제마다 난이도(●○○ ~ ●●●)와 즉시 해설, 결과 화면에 영역별 결과와 채점표
- 문제 읽어주기(브라우저 음성 합성), 최고 기록 저장(기기 브라우저에만 저장)
- 오프라인 동작, 홈 화면에 설치 가능(PWA)
- 디자인: 문제집 + 빨간 펜 채점 컨셉(①②③④ 보기, 손그림 채점 표시, 도장), 글꼴 Do Hyeon · Gowun Dodum

## 실행
빌드 과정이 없습니다. 아무 정적 서버로 폴더를 띄우면 됩니다.

```bash
npx serve .        # 또는: python3 -m http.server 8000
```

서비스 워커와 설치 기능은 `localhost` 또는 HTTPS에서만 동작합니다. GitHub Pages에 올리면 바로 배포됩니다.

## 문제 추가하기
`questions.js`의 `TRACKS[].categories[].questions` 배열에 추가합니다.

```js
{ lv: 2, q: "문제", options: ["보기1", "보기2", "보기3", "보기4"], answer: 0, explain: "해설" }
```

- `answer`: 정답 보기의 위치(0부터) · `lv`: 난이도 1~3
- 영역(카테고리)을 새로 만들면 IQ/EQ 퀴즈에 자동으로 섞여 들어갑니다.
- 파일을 수정한 뒤에는 `sw.js`의 `CACHE` 버전을 올려야 설치된 앱에 반영됩니다.
