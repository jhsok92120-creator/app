# 생각쑥쑥 마음쑥쑥 🌱

초등학생을 위한 **사고력(패턴·논리) + 마음 읽기(감정·친구 관계)** 퀴즈 웹앱(PWA)입니다.

> 이 앱은 연습용 퀴즈입니다. IQ·EQ를 측정하는 검사가 아니므로 숫자 점수를 보여주지 않고 별(⭐)로만 결과를 표시합니다.

## 기능
- 4개 영역 × 12문제: 🔢 패턴 찾기, 🧩 논리 퍼즐, 💗 마음 읽기, 🤝 친구랑 함께
- 한 판에 무작위 8문제, 보기 순서도 섞임
- 문제마다 즉시 해설, 결과 화면에서 다시 보기
- 🔊 문제 읽어주기(브라우저 음성 합성, 저학년용)
- 영역별 최고 기록 저장(기기 브라우저에만 저장)
- 오프라인 동작, 홈 화면에 설치 가능(PWA)

## 실행
빌드 과정이 없습니다. 아무 정적 서버로 폴더를 띄우면 됩니다.

```bash
npx serve .        # 또는: python3 -m http.server 8000
```

서비스 워커와 설치 기능은 `localhost` 또는 HTTPS에서만 동작합니다. GitHub Pages에 올리면 바로 배포됩니다.

## 문제 추가하기
`questions.js`의 각 영역 `questions` 배열에 추가합니다.

```js
{ q: "문제", options: ["보기1", "보기2", "보기3"], answer: 0, explain: "해설" }
```

`answer`는 정답 보기의 위치(0부터)입니다. 파일을 수정한 뒤에는 `sw.js`의 `CACHE` 버전을 올려야 설치된 앱에 반영됩니다.
